Innervision → Salute

CP11 · Primera implementación de M2 · Pendiente de revisión creativa.

  1. Extrae el ZIP completo. No abras el HTML desde dentro del ZIP.
  2. Abre ABRIR_T34_T45_CP11.html con Chrome o Edge. No necesitas instalar programas ni conectarte a internet.
  3. Comienza en Thunder. Desplaza la rueda o desliza hacia abajo hasta Innervision y continúa hacia Salute. Vuelve hacia arriba para invertir el recorrido.
  4. En Innervision aparece «Continuar a Salute». T45 tiene su propio control de progreso, botones de hitos y opción «Reducir movimiento».

Si el equipo de empresa bloquea los archivos HTML locales o WebGL, consulta el LEEME.md para la alternativa con servidor local. F4 está incluido intacto; esta entrega no modifica Nero’s Vice.
