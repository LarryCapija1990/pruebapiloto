CP13 · Misma imagen, contenido dividido

Esta copia conserva imágenes, cámara y scroll de CP13. Se han trasladado las imágenes incrustadas a archivos separados sin reducirlas ni recomprimirlas. Los checkpoints originales no se han modificado.

  1. Extrae ambas partes ZIP en la misma carpeta, conservando las carpetas assets y f4.
  2. Si tienes Python instalado, ejecuta INICIAR_WINDOWS.bat en Windows. En macOS/Linux, ejecuta python3 INICIAR.py en esta carpeta. Se abrirá el navegador.
  3. Alternativa con Visual Studio Code: abre esta carpeta y usa Live Server sobre index.html.
  4. Conserva la ventana del servidor abierta durante la revisión; ciérrala con Ctrl+C al acabar.

No abras index.html por doble clic: esta variante requiere HTTP local para que ambas páginas compartan origen. El HTML autocontenido de CP13 anterior sigue intacto.

Descarga y abre esta copia en el navegador externo, sin usar la vista previa del chat para esta prueba. El error de apertura del chat no tiene una traza accesible en este entorno; no se declara diagnosticada su llamada interna.
